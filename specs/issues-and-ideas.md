
# Repeating tasks
Add the ability to create repeating tasks.
Q: How would the user specify the repetition pattern (e.g., daily, weekly, monthly)?  Can individual instances of the repeating task be edited or deleted without affecting the entire series?  How would the user visualize the repeating tasks on the timeline?  Would there be a way to collapse or expand the repeating tasks to reduce clutter on the timeline?
Q: How do relationships work with repeating tasks?  If task A relates to task B, and both tasks repeat, do the relationships also repeat?  If so, how do we visualize this?
